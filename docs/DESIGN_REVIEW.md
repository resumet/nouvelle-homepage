# 홈페이지 디자인 검토 및 개편

## 디자인 방향

종로를 찾는 여행객을 위한 실사진 중심의 차분한 호텔 홈페이지. 기존 브랜드를 발전시키는 redesign-preserve 모드이며 Astro 정적 구조와 네이티브 CSS를 사용합니다. `design-taste-frontend`의 audit-first 절차를 적용했습니다.

기존 값은 DESIGN_VARIANCE 6 / MOTION_INTENSITY 3 / VISUAL_DENSITY 3. 이번 개편은 DESIGN_VARIANCE 7 / MOTION_INTENSITY 3 / VISUAL_DENSITY 3입니다. 사진의 크기와 위치에 변화를 주되 정보 읽기와 예약을 방해하는 자동 모션은 추가하지 않습니다.

## 변경 전 점검

- 브랜드: 골드 #d4a017, 흰색, 차콜. Montserrat + Noto Sans KR 자체 호스팅. 기존 NOUVER 워드마크 유지.
- 구조: 기존 11개 정적 페이지와 URL, HOME / ROOMS / PRIVATE BATH / LOCATION / EXPLORE 내비게이션, Booking.com 직접 예약 경로 유지.
- 콘텐츠: 운영자 실사진 17장과 확인한 객실 분류, 전 객실 원형 욕조, 지하 욕장 별도 안내, 연락처와 교통 안내가 핵심 자산.
- 반복: 홈 7개 섹션마다 영문 eyebrow가 있고, 마침표 강조와 추상적인 휴식 문구가 반복됨.
- 구성: 동일한 두 칸 이미지·텍스트, 가운데 정렬 제목과 CTA, 세 칸 관광지 박스가 이어져 호텔 고유 공간보다 공통 템플릿 구조가 드러남.
- 읽기: 본문 11~13px와 작은 영문 라벨이 많고, 이미지는 8px·버튼 2px·원형 링크가 혼재함.
- 유지할 기능: 키보드·터치 사진 갤러리, 모바일 메뉴의 포커스 복귀, 고정 모바일 예약, 명도 대비·감소 모션·시스템 다크 모드.
- SEO 기준: 페이지별 기존 제목·canonical·sitemap·Hotel/Breadcrumb JSON-LD·OG 이미지를 유지. 경로 변경 및 리디렉션 없음. 추적 이벤트 없음.

## 적용할 변경

1. 가려진 전체 배경 사진 대신 글과 실사진이 분리되는 첫 화면. 제목·설명·CTA를 정돈.
2. 객실을 박스가 아닌 사진과 캡션으로 소개하고, 데스크톱에서는 사진 크기와 높이에 차이를 부여.
3. 지하 욕장은 넓은 사진으로, 사운드는 작은 실제 디테일 사진으로 보여주어 공간별 비중을 구분.
4. 추상적인 마지막 예약 섹션을 실제 주소와 접근성을 알려주는 종로 여행 안내로 대체.
5. 관광지의 장식용 순번과 외곽 박스 제거. 사진 출처는 필요한 실제 저작자·라이선스 안내로 유지.
6. 본문 크기와 터치 영역 확대. 직각 모서리를 기본으로 통일. 골드는 예약과 핵심 링크에 사용.

예약 버튼의 헤더·푸터·모바일 반복 배치는 PRD의 상시 예약 접근 요구를 따릅니다. 추가적인 동일 목적 CTA 섹션은 제거합니다. 로고의 마침표는 기존 워드마크의 일부이므로 유지하고 본문 제목의 장식 마침표는 제거합니다.

## 스킬 최종 점검

- 브랜드·IA·SEO: 골드 한 색, 기존 로고·탐색 항목·경로·canonical·법적 본문·예약 목적지를 유지.
- 타이포그래피: 자체 호스팅 산세리프, 두 줄 H1, 짧은 설명, 읽을 수 있는 본문 크기. 임의 세리프·이탤릭 장식 없음.
- 구성: 분리된 첫 화면, 높이가 다른 객실 사진, 넓은 욕장 사진, 비대칭 여행지 안내, 간결한 교통 안내. 세 개의 동일한 기능 박스와 장식용 순번 제거.
- 테마·형태: 페이지 단위 시스템 색상 모드, 중간 반전 섹션 없음. 직각 모서리, 그림자·그라데이션·이미지 위 배지 없음.
- 문구: 홈의 추상적 반복 표현을 확인된 객실·위치 안내로 정리. 장식 마침표·em dash·scroll cue·장식 텍스트 띠 없음. 기존 로고의 마침표는 브랜드 보존 예외.
- 상호작용: 새 자동 모션·스크롤 가로채기·모션 라이브러리 없음. 기존 hover/focus, 네이티브 메뉴·갤러리·출처 disclosure 유지.
- 이미지: 실제 호텔 사진과 확인된 관광지 사진. 실제 출처 표시는 장식 캡션 대신 펼쳐보는 안내로 제공.
- 성능: 우선 이미지·지연 로딩·크기 예약·반응형 파일 유지. Tailwind 스캔 범위는 앱 소스로 한정.
- 해당 없음: 폼, 로고 월, 후기, 버전 배지, 벤토, 긴 상품 표, GSAP, React effect는 이 호텔 사이트에 추가하지 않음.

Lighthouse는 로컬 Chrome 모바일 시뮬레이션 측정입니다. 검토용 화면과 보고서는 Git에서 제외한 `artifacts/`에 보관합니다.
