# 홈페이지 구현 및 검증 현황

기준일: 2026-10-28. 루트 PRD v2.1과 이후 운영자가 확인한 정보를 기준으로 구현했습니다. 객실 면적·욕조 안내 등 변경 근거는 [CONTENT_VERIFICATION.md](CONTENT_VERIFICATION.md)에 있습니다.

## 구현 내용

- Astro 7.4.2 / TypeScript 6.0.3 / Tailwind CSS 4.3.3 정적 홈페이지. 의존성 버전과 잠금 파일 고정.
- 메인, 객실 목록, 디럭스·스위트 상세, 지하 욕장, 위치, 주변 관광, 문의, 개인정보 안내, 약관, 404 총 11페이지.
- 골드·차콜 브랜드, Montserrat + Noto Sans KR 자체 호스팅, 반응형·시스템 다크 모드·감소된 모션 설정 지원.
- 운영자 실사진 17장, WebP 51개. 640·960·1280px 중 기기에 맞는 파일을 선택하며 대표 사진 우선 로드, 나머지 지연 로드.
- 디럭스·스위트 각 5장의 사진을 Booking.com 객실별 목록과 대조하여 연결. 지하 프라이빗 욕장 사진 5장, 로비·스피커 사진 각 1장 사용.
- 실사진 확대 갤러리, 좌우 키, 터치 스와이프, 순환 이동, ESC 닫기·포커스 복귀.
- 모바일 모달 메뉴와 하단 고정 예약 CTA. 모든 예약 링크는 같은 Booking.com 호텔 URL로 직접 연결하고 새 탭·noopener noreferrer 적용.
- 주소·국제 형식 전화 링크·이메일 2개·도보/버스/지하철/차량 안내, 확인된 주소의 외부 지도 검색 링크.
- 관광지 6곳의 실사진·설명과 외부 지도 링크. 사진의 촬영자·출처·라이선스 표시. 실제 후기·평점, 미확인 무료 혜택 및 제공하지 않는 서비스를 임의로 추가하지 않음.
- 페이지별 SEO·canonical, Hotel/BreadcrumbList JSON-LD, 실제 객실 사진을 사용한 소셜 PNG, favicon, manifest, sitemap, robots.
- 한국어 공개 UI와 다국어 확장 데이터 타입. 미완성 외국어 페이지·언어 전환 메뉴는 노출하지 않음.
- GitHub Actions 테스트·빌드·Pages 배포와 출시 자료 검사. 서버·DB·폼·자체 예약·결제·로그인·GA4 없음.

Lighthouse 수치는 관광지 사진 추가 전 로컬 미리보기의 모바일 시뮬레이션 측정입니다. 관광지 사진 추가 후 홈·관광 페이지를 375/1440px에서 다시 확인해 모든 사진의 디코딩·출처 표시와 가로 넘침 없음을 검증했습니다. 실제 사용자의 네트워크·기기에 따른 결과를 보장하지 않으며, 자동 접근성 검사는 수동 검수를 대체하지 않습니다.

## 후속 운영

원본 사진은 로컬 제공 폴더에 보존합니다. 배포 파일과 원본 경로·해시·객실별 사진 ID는 `PHOTO_ASSETS.json`, 생성 설정은 `scripts/photo-selections.json`에 있습니다. CI는 저장소의 생성된 WebP를 사용하므로 원본 사진 폴더가 필요하지 않습니다.

스피커 설치 범위·모델과 지하 욕장의 요금·회차·예약 방식, 주차 등 추가 정책은 확정 후 반영합니다. 공식 로고·도메인·외국어 공개 범위가 확정되면 해당 자산과 SEO 설정을 갱신할 수 있습니다. Google Business Profile·네이버 플레이스·카카오맵의 운영자 계정에 홈페이지 URL을 등록하는 작업은 각 서비스 계정에서 관리해야 합니다.

실행·자료 변경·배포 절차는 루트 README에 있습니다. 성능 보고서는 미리보기 실행 중 `npm run audit:mobile`, `npm run audit:summary`로 다시 생성합니다.
